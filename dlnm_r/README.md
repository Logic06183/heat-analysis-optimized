# R-Based DLNM Validation

Sensitivity analysis #1: Distributed Lag Non-linear Models using the R `dlnm` package.

Used to validate the SHAP lag-response profiles from Stage 1 against traditional
epidemiological methods. The original R DLNM script is archived at
`_archive/sep2025_scripts/dlnm_climate_health_analysis.R`.

## Dependencies
- R >= 4.0
- `dlnm` package (Gasparrini 2011)
- `splines` (base R)
